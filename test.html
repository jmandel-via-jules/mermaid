sandboxBaseUrl Feature Test

This page tests the sandboxBaseUrl config option.
When using securityLevel: 'sandbox', relative URLs in diagram links normally don't work because data: URIs have no base URL context. The sandboxBaseUrl option fixes this by pre-resolving relative URLs before embedding in the sandbox iframe.

Test: Clickable Links with sandboxBaseUrl

Click "Docs" to test relative URL resolution, or "GitHub" for absolute URL:

flowchart LR
    A[Home] --> B[Docs]
    A --> C[GitHub]

    click B "./docs.html" "Relative link - should resolve correctly"
    click C "https://github.com/mermaid-js/mermaid" "Absolute link - opens GitHub"
